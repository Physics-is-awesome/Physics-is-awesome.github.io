Hamilton's Equations from the Action Principle

2026-02-14 Mathematical Physics Hamiltonian Mechanics

Hamilton's equations are usually introduced as a Legendre transform away from the Euler–Lagrange equations. That's the fastest route, but it's worth walking through slowly once, since the transform is where the symplectic structure of phase space first appears.

The action

Start from a Lagrangian \(L(q, \dot q, t)\) and the action functional over paths \(q(t)\) between fixed endpoints:

\[ S[q] = \int_{t_1}^{t_2} L(q, \dot q, t)\, dt \]

the action, as a functional of the whole path

Hamilton's principle says the physical path is a stationary point of \(S\): \(\delta S = 0\) for any variation \(\delta q(t)\) that vanishes at the endpoints. Expanding the variation and integrating the \(\delta \dot q\) term by parts gives the Euler–Lagrange equation,

\[ \frac{d}{dt}\frac{\partial L}{\partial \dot q} - \frac{\partial L}{\partial q} = 0. \]

Euler–Lagrange equation

This is second order in time and lives on the tangent bundle — its state is \((q, \dot q)\). The move to Hamiltonian mechanics is a change of coordinates on that state, from \((q, \dot q)\) to \((q, p)\), designed so the equations of motion become first order.

The Legendre transform

Define the conjugate momentum and the Hamiltonian as

\[ p = \frac{\partial L}{\partial \dot q}, \qquad H(q, p, t) = p\dot q - L(q, \dot q, t), \]

conjugate momentum and the Legendre-transformed Hamiltonian

where on the right, \(\dot q\) is understood as a function of \((q,p,t)\) via inverting the first relation. Taking the total differential of \(H\) and comparing it term by term against the differential you'd get from the Euler–Lagrange equation directly yields

\[ \dot q = \frac{\partial H}{\partial p}, \qquad \dot p = -\frac{\partial H}{\partial q}. \]

Hamilton's canonical equations

Two first-order equations instead of one second-order equation — and a state space, phase space, with a very particular geometric structure attached to it.

Why this matters: the symplectic form

Hamilton's equations are the flow of the vector field \(X_H = (\partial H/\partial p,\, -\partial H/\partial q)\) on phase space. That flow preserves the canonical two-form \(\omega = dq \wedge dp\) exactly — not approximately, not only on average. That single fact is responsible for Liouville's theorem (phase-space volume is conserved along the flow) and is the structure that symplectic numerical integrators are built to respect at the level of the discrete update, rather than only the continuous equations. More on that in the next note.

A quick numerical check

As a sanity check, here's a bare-bones (explicit Euler, not yet symplectic — see the next note for why that matters) integration of a simple pendulum, \(H = p^2/2 - \cos q\): 

import numpy as np

def pendulum_rhs(q, p):
    dq = p
    dp = -np.sin(q)
    return dq, dp

def euler_step(q, p, dt):
    dq, dp = pendulum_rhs(q, p)
    return q + dt * dq, p + dt * dp

q, p, dt = 2.0, 0.0, 0.01
energy0 = p**2 / 2 - np.cos(q)

for step in range(20000):
    q, p = euler_step(q, p, dt)

energy1 = p**2 / 2 - np.cos(q)
print(f"energy drift: {energy1 - energy0:.4f}")
# explicit Euler leaks energy steadily — it is not symplectic
